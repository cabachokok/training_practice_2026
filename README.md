Для проверки работоспособности алгоритмов:

1. Скачать файл make_package.py
2. Запустить файл через командную строку с помощью команды make_package.py
После этого будет создана папка media_package с файлами, нужными для проверки работы алгоритма 1

Алгоритм 1:
1. Скачать файл validator.py и сохранить его на одном уровне с папкой с файлами
2. Запустить файл через командную строку с помощью команды python validator.py

Алгоритм 2:
1. Скачать файл apply_profile.py
2. Запустить файл через командную строку с помощью команды python apply_profile.py
