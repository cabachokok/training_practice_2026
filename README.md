Для проверки работоспособности алгоритмов:

Алгоритм 1:
1. Скачать файлы из папки media_package в папку с аналогичным названием
2. Скачать файл validator.py и сохранить его на одном уровне с папкой с файлами
3. Запустить файл через командную строку с помощью команды python validator.py

Алгоритм 2:
1. Скачать файл apply_profile.py
2. Запустить файл через командную строку с помощью команды python apply_profile.py
